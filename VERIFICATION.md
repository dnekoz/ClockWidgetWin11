# Проверки и ручной чек-лист

Дата: 30 октября 2026, часовой пояс пользователя Europe/Moscow. Среда: Windows 11 Pro x64, build 26300; .NET SDK 10.0.403, Runtime/Desktop Runtime 10.0.14. Администраторские права для приложения не запрашивались.

## Выполнено

- Сборка C# с `TreatWarningsAsErrors`: успешно, 0 ошибок и предупреждений.
- Публикация автономного `win-x64` single-file exe и дополнительной сборки DLL: успешно.
- **78/78 автоматических проверок** после финального изменения хранилища: успешно. Вывод сохранён в `artifacts/reports/tests.txt`.
- **83/83 с `--live`** ранее в этой сессии: те же 78 проверок и пять реальных HTTPS-запросов через транспорт приложения. Последующее изменение хранилища не меняло транспорт/разбор ответов.
- До реализации: `curl -4 --noproxy '*'` с проверкой сертификатов для всех пяти выбранных сервисов: HTTP 200, `ssl_verify_result=0`. Ответы двух геосервисов получены для явно заданного `8.8.8.8`.
- После реализации: ipify JSON, icanhazip текст, Amazon CheckIP текст успешно разобраны как публичные IPv4. GeoJS вернул доступную страну, ipwho.is — страну/регион/город для явно переданного `8.8.8.8`.
- Приложение запущено в Windows через стандартный `dotnet ExternalIpWidget.dll`; реальные IP и геолокация успешно получены и записаны в профиль. По данным профиля GeoJS вернул страну, регион и город для обнаруженного адреса.
- Повторный запуск с тем же профилем: второй процесс завершился, первый продолжил работу. Команда показа передаётся через именованное событие.
- В финальной сборке также проверен повторный запуск с другим путём профиля: второй процесс завершился, остался ровно один процесс приложения, второй профиль не создался. Финальная DLL-сборка запущена в стандартном пользовательском профиле и успешно обновила IP/геолокацию.
- Окно настроек открыто и визуально проверено через Computer Use: подписи, единицы интервала/тайм-аута, флажки, пояснения передачи IP и прямого IPv4-соединения, кнопки применения/закрытия видны. Сохранение изменения интервала до 10 секунд подтверждено сообщением «Настройки применены» и файлом JSON; последующие обновления продолжались с применённым интервалом.
- В отдельном чистом профиле финальной DLL-сборки визуально подтверждены 60 секунд и 5 секунд по умолчанию. Проверены отображение трёх IP-сервисов в списке, кнопки управления и открытие редактора ipify с реальным HTTPS URL, JSON-путём и лимитами. Кнопки редактора вынесены в постоянно видимую нижнюю панель, чтобы прокрутка описания не скрывала сохранение.
- При простое с открытыми настройками процесс отвечал, рабочая память около 86 МиБ (одно наблюдение, не длительный бенчмарк). До открытия настроек наблюдалось около 65 МиБ.

Автотесты покрывают:

- строгий публичный IPv4, IPv6 и IPv4-mapped IPv6, private/loopback/link-local/CGNAT/multicast/reserved/documentation/benchmark-диапазоны;
- текст, вложенный JSON, отсутствующие/неверного типа поля, некорректный JSON, JSON Pointer, массивы;
- частичное расположение, пустые компоненты, повторы без учёта регистра, отказ API, несовпадение IP;
- последовательный fallback после тайм-аута, JSON-ошибки, непубличного IPv4 и HTTP-ошибки; пропуск выключенного сервиса и остановку на первом корректном;
- отсутствие геозапросов при отключённой геолокации; явную передачу обнаруженного IP в URL;
- HTTP 429, Retry-After, минимальные паузы, скользящую суточную квоту, сохранение квот/задержек после перезапуска;
- недоступность всех IP-сервисов, сохранение предыдущего IP с отметкой устаревания, первоначальный «IP недоступен», сохранение устаревшей геолокации для того же IP;
- **при смене IP старая геолокация удаляется до завершения геозапроса**, и не появляется после его ошибки; проверяются все промежуточные опубликованные состояния;
- отсутствие пересекающихся циклов, отмену с освобождением блокировки, выключение геолокации с очисткой состояния;
- roundtrip всех настроек, порядок и включение сервисов, координаты на отрицательном мониторе, восстановление из backup, повреждение настроек, валидацию перед сохранением;
- реальное отклонение самоподписанного TLS-сертификата, тайм-аут зависшего IPv4-сокета и запрет HTTP URL.

## Что не удалось проверить полностью

- **Прямой запуск автономного exe заблокирован политикой контроля приложений этой Windows** («Политика управления приложениями заблокировала этот файл»). Exe собран, но не подписан сертификатом издателя. Настройки защиты не менялись. Успешный запуск подтверждён для сборки DLL через установленный .NET. Поэтому запуск exe на чистой Windows без .NET в данной среде не подтверждён.
- Нет отдельной машины Windows 10, x86 или ARM64, чистой VM без SDK и нескольких физических мониторов с разным DPI. Эти конфигурации требуют ручной проверки; код использует PerMonitorV2 и ограничение положения рабочей областью экрана.
- Не выполнялась полная ручная проверка каждого пункта трея, каждого действия редактора сервисов и перетаскивания виджета. Средство автоматизации не перечисляет окно с `WS_EX_TOOLWINDOW`, а во время работы с настройками поступал пользовательский ввод. Не делается утверждение о полном прохождении интерфейсного чек-листа.
- Не выполнялись реальный выход/вход в учётную запись для автозапуска, перезапуск Explorer, физическое отключение сети, смена VPN и длительный тест на протяжении суток. Обработка ошибок, 429, тайм-аутов и смены IP проверена управляемыми тестами; сетевой адаптер пользователя не отключался.
- Не измерялись долгосрочные CPU/энергопотребление/трафик и число запросов других клиентов за тем же NAT.

## Ручной чек-лист для Windows 10/11

Этот список — оставшаяся проверка интерфейса на целевых системах, а не утверждение, что все пункты уже выполнены.

- [ ] Запустить exe обычным пользователем: один компактный виджет, значок трея, нет отдельной кнопки виджета на панели задач.
- [ ] Проверить IP, расположение, время обновления; сравнить с ответом первого доступного сервиса через IPv4.
- [ ] Перетащить виджет, завершить через трей, снова запустить: позиция сохранена.
- [ ] Перенести между мониторами 100/150/200%, затем отключить один монитор: виджет остаётся доступным и читаемым.
- [ ] Скопировать IP кнопкой и через трей, вставить в текстовый редактор: только адрес.
- [ ] Скрыть/показать виджет через трей; скрыть кнопкой «—»; двойным щелчком по трею показать.
- [ ] Навести на трей: IPv4 и доступная геолокация; при сбое IP есть «Данные устарели».
- [ ] Закрыть настройки крестиком и кнопкой: приложение продолжает работать в трее.
- [ ] Нажать «Обновить сейчас» несколько раз: интерфейс отвечает, нет параллельных циклов и обхода пауз API.
- [ ] Изменить интервал, тайм-аут, поверх всех окон, видимость; применить без перезапуска; проверить границы значений.
- [ ] В обоих списках добавить HTTPS-сервис, настроить поля, проверить результат/ошибку; изменить порядок, отключить, включить, удалить.
- [ ] Выключить геолокацию, применить: геоданные убраны; проверить, что геосервисы не запрашиваются. При попытке проверки геосервиса появляется пояснение.
- [ ] Поставить неработающий первый IP/геосервис: работает следующий; успешный первый исключает запросы к последующим.
- [ ] При полном отказе IP-сервисов остаются последний адрес и отметка устаревания; в новом пустом профиле — «IP недоступен».
- [ ] При ошибке геолокации IP остаётся. Сменить VPN/IP: старое расположение никогда не появляется рядом с новым IP.
- [ ] Сменить сетевое подключение: внеочередное обновление после короткой задержки.
- [ ] Включить автозапуск, выполнить выход/вход в Windows; выключить и повторить. Администраторский запрос не появляется.
- [ ] Запустить второй экземпляр: он завершается, виджет первого появляется.
- [ ] Выбрать «Выход»: процесс завершается и значок сразу удаляется; новый запуск успешно работает.
- [ ] Повторить на Windows 10 и Windows 11; отдельно проверить подпись/допуск exe в средах с политиками контроля приложений.
